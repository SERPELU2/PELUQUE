💾 Copias de Seguridad y Control de Datos

Protege tus citas, fórmulas técnicas de tintes y fichas de amigos. Puedes descargar una copia de seguridad en cualquier momento o restaurar una previa para corregir datos.

📥
Descargar Copia de Seguridad

Genera un archivo .json completo con todas tus citas históricas, clientes, observaciones de tintes y horarios. Guárdalo en tu ordenador, pendrive o Google Drive.

📤
Restaurar o Corregir Datos

Selecciona un archivo de copia de seguridad previo para restaurar tu base de datos. También puedes editar el archivo .json en el bloc de notas para corregir cualquier dato antes de subirlo.

🛠️
¿Cómo corregir o editar datos manualmente?

El archivo descargado está en texto claro (JSON). Si necesitas corregir un teléfono, un nombre o añadir una fórmula de tinte en masa, puedes abrir el archivo con el Bloc de Notas de Windows, hacer los cambios, guardarlo y volver a cargarlo usando el botón "Restaurar Datos".
